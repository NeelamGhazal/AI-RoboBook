# Hardware Requirements

## Physical AI Workstation

### Minimum Configuration
- **GPU**: NVIDIA RTX 4070 Ti (12GB VRAM)
- **CPU**: Intel i7 13th Generation or AMD Ryzen 7 7800X3D
- **RAM**: 32GB DDR5
- **Storage**: 1TB NVMe SSD
- **OS**: Ubuntu 22.04 LTS

### Recommended Configuration
- **GPU**: NVIDIA RTX 4090 (24GB VRAM) or RTX 6000 Ada
- **CPU**: Intel i9 13th Generation or AMD Ryzen 9 7950X
- **RAM**: 64GB DDR5
- **Storage**: 2TB+ NVMe SSD
- **OS**: Ubuntu 22.04 LTS

### Budget Configuration
- **GPU**: NVIDIA RTX 4060 Ti (16GB VRAM)
- **CPU**: Intel i5 12th Generation or AMD Ryzen 5 5600X
- **RAM**: 16GB DDR4
- **Storage**: 500GB NVMe SSD
- **OS**: Ubuntu 22.04 LTS
