# RoboBook Introduction

Welcome to the RoboBook Physical AI & Humanoid Robotics Curriculum. This comprehensive documentation covers 4 modules designed for graduate students, educators, and professional developers transitioning to embodied AI.

## Modules Overview

### Module 1: ROS 2 Fundamentals
Learn the Robot Operating System 2 architecture, nodes, topics, services, and create your first ROS 2 node.

### Module 2: Simulation (Gazebo/Unity)
Master physics simulation fundamentals, Gazebo setup, URDF/SDF formats, and Unity integration for robotics.

### Module 3: NVIDIA Isaac
Explore Isaac Sim, Isaac ROS perception, Nav2 path planning, and synthetic data generation.

### Module 4: Vision-Language-Action (VLA)
Implement voice-to-action systems with OpenAI Whisper, LLM cognitive planning, and multi-modal interaction.

## Getting Started

Select a module from the sidebar to begin your journey in Physical AI and Humanoid Robotics.
